# mentor — персональный ментор для обучения и собеседований

Интерактивный CLI-ментор, который учит и тренирует по пяти направлениям:
**Go, PostgreSQL, алгоритмы и структуры данных, System Design, микросервисы**.
Работает в терминале, ведёт диалог через LLM (OpenAI-совместимый шлюз) и
**сохраняет прогресс в Markdown и JSON**.

## Режимы

| # | Режим | id | Что делает |
|---|---|---|---|
| 1 | Обучение темы | `learn` | разбор темы по шагам, наводящими вопросами |
| 2 | Active Recall | `recall` | активное припоминание: вопрос → ответ → разбор |
| 3 | Mock Interview | `interview` | мок-собеседование, строго по одному вопросу |
| 4 | Разбор ошибки | `mistake` | ученик описывает баг — ищем корневую причину |
| 5 | Повторение слабых тем | `review` | быстрые вопросы по слабым темам |
| 6 | Проверка решения задачи | `check` | оценка своего решения без выдачи ответа |
| 7 | Production case | `prod` | реальный прод-сценарий: диагностика и решения |

## Правила обучения (зашиты в промпт ментора)

- объяснять **по-русски простыми словами**;
- **сначала задавать наводящие вопросы**;
- **не выдавать решение алгоритма сразу**;
- в режиме собеседования задавать **по одному вопросу**;
- оценивать **точность, глубину и практическое понимание** (по трём осям);
- **не считать тему изученной после одного правильного ответа** — для уровня
  «изучено» (мастерство ≥ 4) нужна серия верных ответов **в разные дни**.

## Установка и сборка

```bash
cd mentor
make build          # → bin/mentor
make test           # go test ./...
```

Требуется Go 1.23+.

## Настройка LLM

Ключ и адрес шлюза берутся из окружения (в код не зашиваются):

```bash
export MENTOR_BASE_URL="https://<эндпоинт-без-/v1>"   # OpenAI-совместимый шлюз
export MENTOR_MODEL="<модель-чата>"                    # опционально, по умолчанию gpt-4o-mini
export MENTOR_API_KEY="sk-..."                         # или OPENAI_API_KEY / LITELLM_API_KEY
```

Без настроенного LLM ментор запускается в офлайн-режиме (`--demo`) — полезно
для проверки установки.

## Использование

```bash
./bin/mentor                        # интерактивное меню: направление → тема → режим
./bin/mentor --list                 # направления и темы с уровнем мастерства
./bin/mentor --due                  # что пора повторить
./bin/mentor --progress             # показать прогресс

# прямой запуск одной сессии
./bin/mentor --direction go --topic slices --mode recall
./bin/mentor --direction postgresql --topic mvcc --mode interview

# офлайн (без сети)
./bin/mentor --demo --direction algorithms --topic dp --mode learn
```

Флаги: `--root` (где лежат `progress/` и `sessions/`), `--base-url`, `--model`,
`--api-key`, `--direction`, `--topic`, `--mode`, `--list`, `--due`, `--progress`,
`--demo`, `--version`.

Внутри сессии: `/done` — закончить и сохранить, `/skip` — пропустить вопрос,
`/quit` — выйти, `Ctrl+C` — прервать.

## Что сохраняется

```
mentor/
  progress/
    progress.json      # машиночитаемый прогресс (мастерство, серии, расписание)
    progress.md        # человекочитаемая сводка (Obsidian)
  sessions/            # полный журнал каждой сессии (Markdown)
```

Мастерство по теме — `0..5`:

| Уровень | Условие | Пауза до повтора |
|---|---|---|
| 0 | нет верных ответов / серия сброшена | 6 ч |
| 1 | 1 верный | 1 день |
| 2 | серия ≥ 2 | 2 дня |
| 3 | серия ≥ 3 **и** ≥ 2 дня | 4 дня |
| 4 (изучено) | серия ≥ 4 **и** ≥ 2 дня | 7 дней |
| 5 | серия ≥ 5 **и** ≥ 3 дня | 14 дней |

Правило «одного правильного ответа» соблюдается автоматически: за один день
уровень не поднимается выше 2.

## Материалы

Темы ссылаются на конспекты курсов в этом же репозитории (`glubokiy-go/`,
`postgres-qpt/`, `postgres-dev1/`, курсы System Design). Поле `material` в
`internal/curriculum/curriculum.json` — путь к конспекту для повторения.

## Добавить направление/тему

Отредактируй `internal/curriculum/curriculum.json` (схема простая: directions →
topics с `key_points`). Прогресс по новым темам появится автоматически.

## Архитектура

```
cmd/mentor            # точка входа и интерактивное меню
internal/config       # настройки из флагов/env
internal/curriculum   # карта направлений и тем (embed JSON)
internal/llm          # клиент шлюза + офлайн-заглушка
internal/mentor       # сессия, режимы, промпты, разбор метки оценки
internal/progress     # мастерство, расписание повторений, MD/JSON
internal/ui           # цвета и меню (только stdlib)
```

Внешних зависимостей нет — только стандартная библиотека Go.
